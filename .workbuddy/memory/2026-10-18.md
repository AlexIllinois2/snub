## 崩溃日志本地保存（不生成链接）

- 新增 `utils/HCrash.kt`：`HailApp.onCreate()` 中 `HCrash.install()` 安装默认未捕获异常处理器，崩溃时把堆栈+设备信息写入 `filesDir/crash/crash-yyyyMMdd-HHmmss.log`，然后链回系统默认处理器；**不上传、不生成任何链接**。
- `MainActivity` 启动时若有未提示过的日志，弹 MaterialAlertDialog「崩溃日志 / 检测到…是否保存到本地？」[取消][保存]；保存走 `ACTION_CREATE_DOCUMENT`（SAF）由用户选位置，成功后 `HCrash.clear()` 并 toast；取消/关闭仅把日志改名 `.offered`（保留文件、不再重复提示）。
- 字符串加到 values/ 与 values-zh-rCN/strings.xml：title_crash_log / msg_crash_save / action_save / msg_crash_saved / msg_crash_save_failed。
- 注意点：对话框 dismiss 会把文件改名，所以日志内容要在弹窗时先读进内存再写，不能回调时按旧路径读（曾因此保存出 0 字节文件，已修复）。
- MuMu 验证：`am crash io.github.AlexIllinois2.snub.debug`（需应用进程先在运行）触发真实崩溃→日志落盘→重启弹确认框→SAF 保存成功（880 字节完整堆栈，存到 `C:\Users\45574\Documents\MuMu共享文件夹\Download\`）。
- 无签名 APK 产出方式：临时把 release 的 `signingConfig` 改为 null，`assembleRelease` 后立即恢复脚本（git diff 为空）；apksigner 校验 "DOES NOT VERIFY" 确认无签名。产物：`app/build/outputs/apk/release/Snub-v1.11.0-g5f3823a.apk`（5.5MB）。
